# Kits

## Home kit

| Item | Purpose | Notes |
|---|---|---|
| Respirator and safety glasses | Protection when handling media | Required. Ratings: [Safety](../testing/safety.md) |
| Kitchen scale, 0.1 g resolution | Weighing doses | Required (see [Dose](../groups/particulate.md#dose)) |
| Test sieves: #20, #40, #100, #200 (ASTM E11) | Grading media | 850, 425, 150 and 75 µm openings. Sold individually and inexpensively |
| Clear plastic storage bin with lid | Containing media during application | Large enough to operate the device's moving parts inside |
| Wire rack or mesh support | Holding the unit clear of fallen medium | Fits inside the bin (see [Each level](../groups/particulate.md#each-level)) |
| Soft paintbrush, ~2 cm | Working media into seams; cleaning | Dedicated to testing |
| Hand air blower (camera "rocket" blower) | [Between-group cleaning](../testing/conditions.md#between-group-cleaning) | Not canned air |
| Lint-free cloths | Cleaning screens; drying after W | |
| White vinegar | [Carbonate check](media.md#carbonate-check) of sand | |
| Feeler gauge set, 0.05–1.0 mm | Closure gap | Hinged or closing devices only |
| Digital luggage scale or push-pull gauge | Hold force | Devices with magnets, detents or latches only |
| Ruler or calipers | Exposure area | |
| Thermometer/hygrometer | Recording conditions | |
| Water container and tape measure | W immersion and depth | Deep enough for the depth tiers claimed |
| Water thermometer | Recording water temperature | |
| Second phone or camera | Photos, audio and video records | |
| UV flashlight (365 nm) + UV-fluorescent pigment powder | Making ingress visible | Optional. Preparation: [Test Media](media.md#uv-tracer) |

> **Note (informative):** A scale is required because volume measures are not accurate enough. Humidity is recorded because it affects how powders clump.
