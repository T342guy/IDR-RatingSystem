# Reporting

## Report contents

A D and G test report shall contain:

| Item | Tier |
|---|---|
| Tier (home or lab) | Both |
| Device model, firmware version, number of units, serial numbers | Both |
| Condition of each unit (and assigned wear level for lab units) | Both |
| Kit and media used: sources, sieve fractions, tracer | Both |
| Temperature and humidity | Both |
| Exposure area and calculated doses | Both |
| Baseline and per-level measurements for every applicable effect | Both |
| Photos, audio and video for every level | Both |
| Chosen maximum level, why testing stopped, and measurements after recovery cleaning | Home |
| Teardown findings and photos for every unit | Lab |
| Final D and G codes for each unit | Both |
| IDRS digits | Lab |

Report contents for U and W, and a report template, are [TBD].

An IDRS code is valid only when the report is published alongside it (see [IDRS Short Code](../rating/idrs.md#eligibility)).
