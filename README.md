# IDR-RatingSystem
 T342's own rating system to improve upon the IP rating system.

The IDR rating system (aka Ingress & Durability Rating) is an unofficial and open source durability rating system meant to improve the issues stemming from the IP rating system that does not cover the issues with in-use durability, or mechanical counterparts of devices (eg, the iPhone Duo's hinge, getting full of dirt whilst it established an IP68 rating).

This rating system is made by a single person and is work in progress, unofficial and incomplete. You may personally write your own ratings based off of reports you have gathered (jerryrigeverything teardowns, or iFixit teardowns).

This repo is an obsidian vault, and an mdbook page, so hyperlinks between pages may be seen.
